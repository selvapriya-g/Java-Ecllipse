# Java String Testing using JUnit

This project demonstrates Java String-related testing using **JUnit**. The test cases were developed and executed using **Eclipse IDE**.

## Technologies Used

* Java
* JUnit
* Eclipse IDE

## Features

* String operation testing
* `StringBuilder` / `StringBuffer` testing
* Testing `capacity()` method
* JUnit test case implementation
* Test execution and result verification

## Purpose

The project was developed as part of hands-on practice in the **Test Engineer domain**, focusing on Java, JUnit, and unit testing concepts.
